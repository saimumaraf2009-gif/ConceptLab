# ConceptLab starter

A lightweight, responsive, single-file Bengali educational website.

## What's included
- Responsive homepage and chapter library
- Search and subject filters
- 16 planned chapters
- Starter lessons for Matrices & Determinants, Safe Use of Laboratory, and Physical World & Measurement
- Interactive concept checks
- Source links and creator credit

## Run locally
Open `index.html` in a modern browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `conceptlab`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then Save.
6. Wait for the site URL to appear on the Pages settings screen.

GitHub Pages serves static HTML/CSS/JavaScript. This starter does not need an API key or database.

## Important content note
The three lesson pages are initial educational drafts, not a fully verified replacement for the current HSC textbook. Before using them for exam preparation, compare definitions, notation, and syllabus coverage with the current NCTB-prescribed books and ask a subject teacher to review them. Add precise book/chapter/page references as the content is verified.
